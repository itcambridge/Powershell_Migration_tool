# Migration Command Builder

Web application that configures one migration run and generates PowerShell for an engineer to review, copy, and run elsewhere. It does not execute commands. Start a new run for another domain.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm test
npm run build
```
